# Sources & attribution

## Summary

This wiki synthesizes general FFF knowledge and A1 Mini-specific practice. It does not paste forum threads wholesale; it absorbs patterns and cites origin. The local ebook is **CC BY-SA 4.0** — derivatives keep attribution and ShareAlike.

## When to use

- Before republishing wiki excerpts.
- When adding a new process number (local calibration vs external source).
- In `3ds/plan/*.md` when justifying a decision with a reference.

## A1 Mini rules

- Prefer official Bambu wiki for hardware/maintenance procedures.
- Prefer Ellis / Teaching Tech for calibration method (towers, flow, retract).
- Prefer CNC Kitchen / walls-vs-infill literature for strength decisions.
- Adapt Prusa KB / FixMyPrint taxonomies to A1 Mini (direct drive, 180³ bed, PEI).
- Dual-track: community baseline + **validate on printer**.
